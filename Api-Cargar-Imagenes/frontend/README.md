# API Students - Frontend

Aplicacion React para carga de imagenes con interfaz de modal alerts.

## Requisitos

- [Node.js](https://nodejs.org/) 18 o superior
- [pnpm](https://pnpm.io/) como gestor de paquetes

## Instalacion

```bash
pnpm install
```

## Variables de entorno

El frontend se conecta al backend. Asegurate de que el backend este corriendo en el puerto configurado.

## Ejecucion

```bash
# Development
pnpm dev

# Build para produccion
pnpm build
```

El frontend estara disponible en `http://localhost:5173`.

## Stack tecnologico

- **Framework**: React 18 + Vite
- **Estilos**: Tailwind CSS 4
- **Componentes**: MUI, Radix UI
- **Router**: React Router
- **Formularios**: React Hook Form
- **Graficas**: Recharts
